# Free Christmas card message writer (one HTML file, nothing stored)

Add everyone on your Christmas card list, say who each person is (Mum and Dad, a neighbour, your boss, your child's teacher, someone having a hard time and so on) and pick a warm, funny or short style. You get a different message for each person, with their name at the top. Change the wording, copy it, then write it out by hand, or print the whole list to work through with a pen. No sign-up, no server, no cookies, no build step: it is one `index.html` file.

**Use it now, no install:** download `index.html` and open it in any browser, or browse all 77 messages by person on the page version at [tchworks.co.uk/free/what-to-write-in-a-christmas-card-2026](https://www.tchworks.co.uk/free/what-to-write-in-a-christmas-card-2026/?utm_source=github&utm_medium=repo&utm_campaign=card-message-repo).

## What is in it

- 11 groups of people, 7 messages each (3 warm, 2 funny, 2 short): 77 messages, all written by TCH Works.
- The same messages are in `messages.json` if you want to reuse them in your own tool.
- Messages in one list are not repeated for the same group until they run out.
- The name you type is only used in your browser; nothing leaves the page.

## Change it

Open `index.html` in a text editor. The messages are in the `G` array near the bottom, as `[style, text]` pairs inside each group.

## Limits

Messages are starting points. Add a shared memory or a name where you can; people notice.
